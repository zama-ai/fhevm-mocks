## Gap

**Audit 2026-11-18, [GAP], loose check.** ownedTsconfigs reads the `.` root's own folder without recursion and then only members and non-packages (tsconfig-paths.ts:114-116). A tsconfig directly in a cluster root, for example hardhat/v3/tsconfig.json with "include": ["./deleted"], is skipped (kind workspace-root, member=false); so is a tsconfig in a root-owned subfolder such as scripts/tsconfig.json. fhevm-npm/tsconfig.json is outside the inventory and is not read either.
