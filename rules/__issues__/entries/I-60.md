## Gap

**[GAP], no check.** Nothing under a published `pkg/` may import a `…-dev` package, and the repository follows it, but no check scans the source files. Only the Prettier and ESLint configs of a published payload are scanned. The cleartext consumer fixtures install the private helpers, so the consumer test would not catch such an import either. NR-41 is `[GAP]` until then.

## Where

`fhevm-npm/base/checks/scripts.ts:657-676` (the only scan, config files only)

## Fix

Add a check that scans every source file under each published `pkg/` for an import or require of a specifier ending in `-dev`, and a test with a payload that imports one.

Affects [NR-41](../../fhevm-npm/rules/entries/NR-41.md).
