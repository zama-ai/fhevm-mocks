## Gap

**[GAP], no check (D10 decided).** A published payload with a public API declares `exports`; a consumer, such as a template, has no public API and declares none. The repository follows it: the two host-contracts generations, `forge-fhevm-std` and both plugins declare `exports`; both templates declare none. No check reads `exports`: the schema makes it optional and `test-consumer` falls back to `main`.

## Where

`fhevm-npm/base/npm.ts:29`; `fhevm-npm/base/test-consumer.ts:1253-1256`

## Fix

Add a check: every `published` payload distributed to npm declares `exports`; a mirror-only `published` payload and every `internal-consumer` declare none. The inventory has no consumer field, so mirror-only stands in for a published consumer; add a real field if a consumer is ever published to npm. Minimality stays guidance.

Affects [NR-48](../../fhevm-npm/rules/entries/NR-48.md).
