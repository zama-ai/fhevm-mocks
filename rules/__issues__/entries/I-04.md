short: Four requirements of the old package definitions may have no rule, and each one needs approval as a new rule.
old: Q6

Rules already hold most requirements of the old definitions: NR-03, NR-05, NR-09, NR-39, NR-40, NR-55, and NR-64. These four still need a check against the rules. Each one that no rule holds becomes a new rule in the Packages group, if the owner approves it:

- A published package is not private.
- A dev package wraps exactly one published package.
- A non-package has no `name`, version, or scripts, and is never a workspace member.
- A workspace root is private, never published, and never a member of anything.

Affects [ND-03](../../fhevm-npm/definitions/entries/ND-03.md).
