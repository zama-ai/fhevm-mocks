May a test of the debug config change the chain id around `new`?

- **Yes:** FR-21 `STALE`, and the rule gets an exception.
- **No:** FR-21 `VIOLATED`.

The reviews disagree on the current tags of some of these rules. The tag in each rule is a vote, not a verdict, until this decision.

Affects [FR-21](../../forge-fhevm-std/rules/entries/FR-21.md).
