## Gap

The old books, `fhevm-npm-docs/FHEVM_NPM_RULES.md` and `foundry/forge-fhevm-std/rules.md`, are deleted, and `rules/` replaces them. Comments in the source, the tests, the scripts, and the `Makefile` still cite their numbers. `.CLAUDE.md` requires a comment to cite a rule by its ID.

The column "Old number" of each rule index maps an old number to its ID, so each citation can be rewritten.

## Where

Search the internal text, leaving out the frozen `<vN-1>`:

```sh
git grep -nE "RULES [0-9]|§ ?[0-9]|rule [0-9]+\.[0-9]|rules?\.md [0-9§]" -- '*.ts' '*.sol' '*.mjs' '*.sh' Makefile ':!host-contracts-cleartext/<vN-1>'
```

## Fix

Rewrite each citation as the ID of the rule. Three citations sit in public files, where R-01 forbids any citation: issue I-124 replaces those with the reason instead. The labels that the checks print, such as `'3.4.7'`, are issue I-07.
