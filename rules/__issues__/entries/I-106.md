## Gap

**Audit 2026-11-18, [GAP], loose check.** In the mirror-only payload hardhat/v2/fhevm-hardhat-template/pkg, replace LICENSE by a symlink to ../../../../LICENSE: existingFile() uses statSync, which follows the link, so the 'regular file' test passes, and published-files.ts skips mirror-only payloads; the mirror then receives a dangling link. On a case-insensitive disk a file named `license` also passes there, but the Linux CI catches that one. Narrow: an npm-distributed payload is safe because npm does not pack a symlink and 5.2.6 then reports it.
