The kinds become npm definitions after ND-04: ND-05 "Dev package", ND-06 "Shared helper", ND-07 "Internal consumer", ND-08 "Standalone project", ND-09 "Non-package", and ND-10 "Private development package", which NR-01 uses for the three kinds `dev`, `shared-helper`, and `internal-consumer`.

- **Decide:** whether the manifest values in code font, such as `dev`, are aliases. Recommended: no. An alias names the same concept, and `dev` is a value that the manifest schema owns and can rename. ND-03 and ND-04 have no such alias today.
- **Decide:** the tag. Recommended: `STABLE`, because a package kind depends on the layout of the workspace, not on the protocol. ND-03 and ND-04 already use it.

The example of "Standalone project" is no longer `hardhat/v2/fhevm-hardhat-template`, which is a dev package.

Affects [ND-03](../../fhevm-npm/definitions/entries/ND-03.md), [ND-04](../../fhevm-npm/definitions/entries/ND-04.md), [NR-01](../../fhevm-npm/rules/entries/NR-01.md).
