## Gap

**Decided (D15):** an attempt may link through a byte-identical copy of the manifest it started from, kept in its own folder, as an event can. The check finds an attempt's target by exact path, so a copy path fails with "does not resolve to an event of this stack" before the copy allowance runs. Latent: no attempt exists today. NR-83 is `[VIOLATED]` until then.

## Where

`fhevm-npm/base/checks/deployments.ts:646-648`

## Fix

When the path is not an event's manifest, find the target event by the sha256 of the copy, then run the same `checkPrevious`. Add a test with an attempt that links through a kept copy.

Affects [NR-83](../../fhevm-npm/rules/entries/NR-83.md).
