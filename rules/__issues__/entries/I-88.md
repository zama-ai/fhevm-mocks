## Gap

**Audit 2026-11-18, [GAP], wrong check.** Compliant change that fails: extends = { path = "../../foundry.base.toml", strategy = "replace-arrays" } in [profile.default]. Forge accepts the table form (the installed forge 1.5.1 binary contains the strategies `replace-arrays` and `no-collision`), but the regex at foundry.ts:204 accepts a quoted string only. Any other valid TOML spelling fails too, for example the header `[ profile.default ]`. NR-43c says a Foundry answer comes from `forge config --json`, never from a parsed foundry.toml; this is the one place that parses it. Also loose: only a foundry.toml in an inventoried package's own folder is read (foundry.ts:27-29), so a foundry.toml in a subfolder, without extends, passes.
