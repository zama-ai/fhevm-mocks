title: Where `exports` belongs
short: The old definition of a published package says it declares `exports`, which is a requirement, and NR-48 already holds it.
old: Q3
---

NR-48 says that "a payload with a public API declares `exports`", and that a consumer declares none. A requirement goes into a rule, never into a definition.

- **Answer A (recommended):** ND-03 does not mention `exports`, and NR-48 stays as it is.
- **Answer B:** every published package declares `exports`. NR-48 and NR-54 change.

Affects [ND-03](../../fhevm-npm/definitions/entries/ND-03.md), [NR-48](../../fhevm-npm/rules/entries/NR-48.md), [NR-54](../../fhevm-npm/rules/entries/NR-54.md).
