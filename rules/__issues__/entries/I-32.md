Must the debug config return what upstream returns where upstream returns 0, as for `getConfidentialProtocolId`?

- **Yes:** FR-22 `VIOLATED`.
- **No:** FR-22 `STALE`, and the rule states the exception.

Affects [FR-22](../../forge-fhevm-std/rules/entries/FR-22.md).
