## Gap

**[GAP], no check.** A generation's vendored entries must pin one upstream tag and commit, and the repository follows it, but each pinned entry is checked alone. Only the write tool keeps them together, so a hand edit that moves one entry passes, and `check:zama-config` then grades against the wrong commit. NR-42c is `[GAP]` until then.

## Where

`fhevm-npm/base/checks/vendored.ts:362-397` (per-entry check); `fhevm-npm/base/bump-vendored.ts:8-10`

## Fix

Add a check that groups a generation's pinned entries and fails when their `tag` or `commit` differ, and a test with two entries that disagree.

Affects [NR-42c](../../fhevm-npm/rules/entries/NR-42c.md).
