## Gap

The four `host-contracts-cleartext` consumer fixtures import the private helpers `@fhevm/sdk-common-dev` and `@fhevm/sdk-vendored-dev`, which a real consumer cannot install. No rule forbids it, but it weakens what the consumer tests prove.

## Where

for example `host-contracts-cleartext/v14/test-consumer/esm/src/index.ts:12-13`

## Fix

Remove the imports, or write a rule that allows them.
