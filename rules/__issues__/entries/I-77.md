## Gap

**Audit 2026-11-18, [GAP], loose check.** Three changes pass. (1) Bare tsc with a valued flag: "lint": "tsc --noEmit --pretty false" on a solution-style ./tsconfig.json; the positional `false` makes the parser skip the invocation (tsc-mode.ts:121). (2) Inheritance: "lint": "tsc -p ./tsconfig.lint.json --noEmit" where tsconfig.lint.json is { "extends": "./tsconfig.json", "references": [...] } and ./tsconfig.json has "files": []; isSolutionStyle reads the raw file, sees no `files`, and passes, while tsc inherits the empty `files` and checks nothing. (3) A path-qualified binary, `./node_modules/.bin/tsc -p ...`: the token is not `tsc` (tsc-mode.ts:98). Only package.json scripts of inventoried packages are read; a tsc call in the Makefile, a shell script or fhevm-npm/package.json is not.
