Write the place of a generation with the notation below, never its number. A generation number is true for one rotation only. After the next rotation, `v13` still reads as a fact but points at the wrong generation, and no check notices. A name relative to `<vN>` stays true across every rotation.

[D-02](../../definitions/entries/D-02.md) defines a generation. This rule covers only versions that rotate as generations do, not a tool version, a compiler version, or the version of one contract. Internal text is all text that [R-01](R-01.md) does not call public. Public text names the versions that its reader installs, so this rule does not apply to it.

## Write the place with the notation

| Write          | Means                                                   | Instead of               |
| -------------- | ------------------------------------------------------- | ------------------------ |
| `<vN>`         | The current generation, which this branch develops      | `v14`                    |
| `<vN-1>`       | The previous generation                                 | `v13`, "the old version" |
| `<vN-2>`       | The generation two steps back                           | `v12`, `v(N-2)`          |
| `<vN+1>`       | The next generation, not rotated in yet                 | `v15`                    |
| `<vM>`, `<vN>` | Two generations, and the text states how M relates to N | `v13` and `v14`          |
| `<N>`          | The version of the current generation, `major.minor`    | `0.14`, `0.<N>`          |
| `<N-1>`        | The version of the previous generation                  | `0.13`, `0.<N-1>`        |

- `<vN>` always means the current generation of the branch that holds the text. On a release branch, `<vN>` is the generation of that release branch.
- State the relation between M and N in the sentence that introduces `<vM>`. For example: "The SDK refuses a stack on `<vM>`, with M < N." If the text states no relation, the statement holds for every M.
- "The current generation", "the previous generation", and "the next generation" mean the same as `<vN>`, `<vN-1>`, and `<vN+1>`. Use the words or the notation, but not both in one passage.
- In Markdown, put the notation in backticks, as in `` `<vN>` ``. Without backticks, Markdown reads `<vN>` as an HTML tag and drops it from the page.
- In a path, the notation replaces the number, as in `host-contracts-cleartext/<vN>/pkg/src/`.
- `<vN>` names a generation and its directory, as `v14`. `<N>` is its version, as `0.14`. Build a version or a branch from `<N>`: `<N>.0` for the first release of the generation, `<N>.x` for all its releases, and `release/<N>.x` for its branch.
- Never write `0.<N>`, as in `0.<N>.x`, `^0.<N>.0`, or `release/0.<N>.x`. The `0.` holds only before 1.0. From protocol v1.0 on, the version of a generation is `1.0`, so `<N>` already holds the whole version, and `0.<N>` would point at a version that does not exist.

## Keep the number in four cases

1. **Text frozen with its generation.** [R-04](R-04.md) keeps the copy of the previous generation byte-identical to its release branch, and that includes its text. Never rewrite a number in a frozen copy or in a generated copy. If the source is not frozen, rewrite the number at the source.
2. **Dated records.** Commit messages, PR descriptions, and incident notes record what was true on their date. Nobody rewrites them later, so they can name a generation by its number.
3. **A fact about one past release.** "Sepolia ran `FHEVMExecutor v0.4.0` after this SDK vendored `0.13.6`" stays true. Keep the number, and keep the sentence in the past tense.
4. **A value that code needs.** A script that opens a directory, fetches a tag, or pins a package needs the real number. Write the number once, in one place in the package, and make every other file read it from there. The comments around that value still use the notation.

## Find the text that names a number

To list the text that names a number, search the internal text:

```sh
grep -rnE '\bv[0-9]{2}\b|v\(N|V\(N|0\.<N' <rule folders and internal sources>
```

Fix each match, unless one of the four cases above covers it. A rule whose text names a number gets the rule tag `STALE`, even before the next rotation. Code or a comment that names a number makes this rule `VIOLATED`. The old notations `v(N-2)` and `V(N)` become `<vN-2>` and `<vN>`, and `0.<N>` becomes `<N>`.
