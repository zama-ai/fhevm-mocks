A rule is internal and changes: its ID can be retired, and its text is rewritten as the code moves. A public reader cannot open a rule book, so a reference sends them to text they never see, or to text that has since changed. Public text is:

- the source files that the `PUBLIC_API.md` of the package, next to its rule book, names public, including their comments and documentation comments;
- every error message a user can see, whatever file builds it, including a message built by an internal file;
- the user documentation of the package, and any docs site.

A file is not public by being published: a package can ship internal files too. Internal text may cite rules: internal source files, tests, build scripts, CI, the rule books, commit messages and PRs. Where public code needs the reason behind a rule, it states that reason in one sentence instead of citing the rule.
