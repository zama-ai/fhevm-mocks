title: Never edit a generated file
short: Edit the source of a generated file, never the file itself.
check: missing

---

Edit its source, then run `make generate` at the workspace root, which runs every generator in order, from each source down to its last copy. The next run overwrites a copy, so an edit made in one is lost, with no warning.
