title: Never write into a generated directory
short: Never write into a directory that a generator owns, by hand or from another generator.
check: missing
issues:
  - I-14
  - I-18
---

The owning generator deletes the directory and rebuilds it, so a file added there is lost, or survives only when its writer happens to run last. Put the file in the source directory, and the generator copies it.
