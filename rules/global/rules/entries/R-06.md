A definition is registered or loose. A registered definition lives in the `entries/` folder of a definition folder, such as `global/definitions/`, and appears in its index. A loose definition explains a term only where the term is used, for example in a sentence of a rule or in a code comment.

- To register a definition, use [the `reg-definitions` skill](../../../../.claude/skills/reg-definitions/SKILL.md) and [the `reg` skill](../../../../.claude/skills/reg/SKILL.md). Never write a file in a definition folder another way.
- Every registered definition passes `generate-index.mjs --check`.
- To give a term another meaning, change its registered definition with the skill, or register a new one. Never redefine a registered term locally.

A registered definition has an ID that never changes, aliases that the script checks, and one place where every reader finds it. A loose definition has none of these, so two loose definitions of one term can drift apart and nothing notices.
