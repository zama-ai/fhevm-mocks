short: A definition that explains a term only where the term is used, outside any definition folder.
---

A loose definition explains a term only where the term is used, for example in a sentence of a rule or in a code comment. It has no ID, and no script checks it.

Loose definitions are allowed. A loose definition never contradicts a registered definition of the same term. If the two disagree, the registered definition holds, and the loose one is the text to fix. To give a registered term another meaning, change its registered definition with the `reg-definitions` skill instead of redefining it locally. [R-06](../../rules/entries/R-06.md) gives the rule.
