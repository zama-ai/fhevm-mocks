---

A definition tag sits in the `tag` field of the front matter of each registered definition. It says whether the definition can change, and whether the definition is still in use.

[`TAGS.json`](../../../../.claude/skills/reg-definitions/TAGS.json), in the folder of the `reg-definitions` skill, lists the definition tags and their meanings. It is the only list. Every generated index, such as [README.md](../README.md), shows it as a table.

A definition tag is not a rule tag. A rule tag says whether a rule and the code agree. Write "definition tag" or "rule tag" wherever "tag" alone could mean either.
