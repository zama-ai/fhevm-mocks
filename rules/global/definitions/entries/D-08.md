---

A rule folder is a registry folder whose `README.md` declares `kind: rules`. Its `entries/` folder holds one file per rule, named after the ID of the rule, its `README.md` indexes them, and its `groups/` folder holds the generated group pages. For example, `global/rules/` holds the global rules, from `entries/R-01.md` on.

[The `reg-rules` skill](../../../../.claude/skills/reg-rules/SKILL.md) gives the fields of a rule, and [the `reg` skill](../../../../.claude/skills/reg/SKILL.md) gives the layout and the script.

A rule book not converted yet keeps its rules in topic files, next to a `rules.md` that indexes them, as `foundry/forge-fhevm-std/rules/` does today.
