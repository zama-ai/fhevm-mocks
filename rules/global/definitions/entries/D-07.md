A definition folder is a registry folder whose `README.md` declares `kind: definitions`. Its `entries/` folder holds one file per registered definition, named `<ID>.md`, its `README.md` indexes them, and its `groups/` folder holds the generated group pages. For example, `global/definitions/` holds the global definitions, from `entries/D-01.md` on.

Every file in the `entries/` folder of a definition folder is a registered definition. [The `reg-definitions` skill](../../../../.claude/skills/reg-definitions/SKILL.md) gives the format of the files, and `generate-index.mjs` checks them.
