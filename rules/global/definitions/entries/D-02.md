name: Protocol generation

short: One iteration of the Zama protocol, named today by its major and minor version numbers.
---

A protocol generation is one iteration of the Zama protocol. Each new generation replaces the current one. Today, the major and minor version numbers name a generation, and every release of that generation shares them:

| Generation    | Releases |
| ------------- | -------- |
| protocol v13  | `0.13.x` |
| protocol v14  | `0.14.x` |
| protocol v1.0 | `1.0.x`  |

This definition describes the protocol as it works now. If the protocol design changes, what makes a new generation and how a generation is numbered can change too.

Internal text names a generation by its place, as in `<vN>` or `<vN-1>`, never by its number. [R-05](../../rules/entries/R-05.md) gives the notation.
