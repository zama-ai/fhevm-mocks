A non-canonical chain is any host chain of an FHEVM group other than its canonical chain. Today:

| Group     | Non-canonical chains                                            |
| --------- | --------------------------------------------------------------- |
| `mainnet` | Polygon (137)                                                   |
| `testnet` | Polygon Amoy (80002), BSC Testnet (97)                          |
| `devnet`  | Polygon Amoy (80002), BSC Testnet (97), Ethereum Hoodi (560048) |

A group can have any number of non-canonical chains, none included.

This definition describes the protocol as it works now. A group can add or remove non-canonical chains.
