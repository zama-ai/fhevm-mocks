---

A registry folder holds one kind of entry. Its layout is the same for every kind:

- `README.md`: the index. Its front matter names the kind and the ID prefix and declares any groups. The script `generate-index.mjs` of [the `reg` skill](../../../../.claude/skills/reg/SKILL.md) generates the part between its two markers.
- `entries/`: one file per entry, named after its ID, as in `entries/D-02.md`. The front matter of each file holds the data of the entry.
- `groups/`: the generated pages, one per group, and `all.md` with every live entry.

The kind sets the letter of the IDs, the fields of an entry, and the list of tags. A definition folder is a registry folder of the kind `definitions`.
