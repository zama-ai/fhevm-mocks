An FHEVM group is one deployment of the Zama protocol. One gateway, one relayer, and one KMS serve the host contracts that the group deploys on each of its host chains ([D-13](D-13.md)). Every group has exactly one canonical chain ([D-14](D-14.md)).

Three groups exist today:

| Group     | Canonical chain             | Non-canonical chains                                            |
| --------- | --------------------------- | --------------------------------------------------------------- |
| `mainnet` | Ethereum Mainnet (1)        | Polygon (137)                                                   |
| `testnet` | Ethereum Sepolia (11155111) | Polygon Amoy (80002), BSC Testnet (97)                          |
| `devnet`  | Ethereum Sepolia (11155111) | Polygon Amoy (80002), BSC Testnet (97), Ethereum Hoodi (560048) |

In `fhevm-chains.config.json`, a group is an entry of `networks`, with its `relayerUrl` and its `gateway`.

The local stack is not an FHEVM group. It is the cleartext mock that a test deploys on a local chain, as on chain 31337. No gateway, relayer, or KMS serves it. The code calls it the `local` group, as the `fhevmGroup` field of forge-fhevm-std does, and so do some rules. That name does not make it an FHEVM group.

This definition describes the protocol as it works now. If the protocol design changes, what a group holds can change too. Groups can also be added or removed, so the table above can change.
