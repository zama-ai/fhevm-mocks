`attw --pack` judges the packed types in every
mode the payload's module formats reach, and does not run for a Solidity-only payload ([NR-47](NR-47.md)); `test:consumer` adds
runtime execution and the package's actual supported toolchain. Neither substitutes its own convenient resolution mode
for the consumer contract. The declaration probe of `test-consumer` runs under `nodenext` ([NR-50](NR-50.md)) and adds to whatever
the fixture's own `test` script compiles; `test-consumer` compiles nothing else itself. A Hardhat v2 consumer's `node10`
resolution is traced by the plugin's own test, not by `test-consumer` ([NR-50](NR-50.md)).

```text
✅ attw --pack: static resolution matrix for the formats the payload ships
✅ test:consumer: supported toolchain, exact paths and runtime execution
✅ hardhat/v2/plugin's own test: node10 trace of the linked pkg/
❌ tsc under nodenext only, with no node10 trace anywhere: no proof that a Hardhat v2 consumer resolves the package
```
