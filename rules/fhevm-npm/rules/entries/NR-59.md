Each candidate in `node_modules` must not be a
symlink, and its real path must stay below the temporary consumer. The test starts without the fixture's top-level
`node_modules` and without any installation root's lockfile. The only lockfile it can carry is the fixture's own
committed `package-lock.json`, which `test-consumer` replays with `npm ci --install-links`. A consumer that is a
workspace member has none, since its installation root locks it ([NR-64](NR-64.md)), and is resolved fresh with
`npm install --install-links`; so is an isolated fixture with no committed lockfile, which [NR-54](NR-54.md) already rejects, with a
warning that `--ci` turns into an error.

```text
✅ /tmp/fhevm-consumer-abc123/node_modules/@fhevm/hardhat-plugin
❌ /repo/hardhat/v2/plugin/pkg
```
