Any package of the family (the dev package, its payload, its consumers)
counts as that generation. A `file:` spec is resolved by directory; a version spec by name, and when the name is
shared by several generations the spec must be the exact version of one of them, otherwise the validator cannot tell
which generation is meant. A generation may always depend on itself. The one cross-generation edge is narrow on all
three axes: the source is the `<vN>` dev package itself (not its payload, not a consumer below it), the target is the
`<vN-1>` **dev** package (not its payload), and the field is `devDependencies` (`<vN-1>` exists only to be tested
against, so nothing may put it on a shipping path). Every other edge into the family — a consumer on `<vN-1>`, anyone
on a generation that is neither — fails. The rule also covers a dependency no committed `package.json` declares: the
spec the Hardhat template mirror patch injects into the rendered template is resolved as if the template package had
declared it.

```jsonc
// ✅ In hardhat/v3/plugin/pkg: the current generation's payload.
"@fhevm/host-contracts-cleartext": "file:../../../../host-contracts-cleartext/<vN>/pkg"

// ✅ In host-contracts-cleartext/<vN> (<vN>): the <vN-1> dev package, for the upgrade e2e. The only edge into <vN-1>.
"devDependencies": { "@fhevm/host-contracts-cleartext-<vN-1>-dev": "file:../<vN-1>" }

// ❌ In host-contracts-cleartext/<vN> (<vN>): the same target from a runtime field. <vN-1> is for tests only.
"dependencies": { "@fhevm/host-contracts-cleartext-<vN-1>-dev": "file:../<vN-1>" }

// ❌ In host-contracts-cleartext/<vN> (<vN>): <vN-1>'s payload rather than its dev package.
"devDependencies": { "@fhevm/host-contracts-cleartext": "file:../<vN-1>/pkg" }

// ❌ In host-contracts-cleartext/<vN>/pkg: below <vN> is not <vN>; only the dev package carries the edge.
"devDependencies": { "@fhevm/host-contracts-cleartext-<vN-1>-dev": "file:../../<vN-1>" }

// ❌ In hardhat/v3/plugin/pkg: a consumer on <vN-1>. When <vN+1> arrives this is the pin that is forgotten.
"@fhevm/host-contracts-cleartext": "file:../../../../host-contracts-cleartext/<vN-1>/pkg"

// ❌ In common: nothing outside <vN> may depend on <vN-1>.
"devDependencies": { "@fhevm/host-contracts-cleartext-<vN-1>-dev": "0.0.0" }

// ❌ A range over a name two generations share: which payload is meant cannot be read off the spec.
"@fhevm/host-contracts-cleartext": "^<N>.0"
```
