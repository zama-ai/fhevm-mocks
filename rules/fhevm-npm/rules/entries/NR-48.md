What it omits is unreachable, provided the consumer resolves in a mode that honors it. A consumer, such as a
template, imports payloads and is imported by nothing: it has no public API and declares no `exports`.

```text
✅ a plugin: "exports": { ".": …, "./package.json": "./package.json" }
✅ a template: no "exports"
❌ a plugin with no "exports": every file it ships can be imported, so every refactor can break a consumer
```
