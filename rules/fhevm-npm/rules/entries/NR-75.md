It compares entries with real
`package.json` files and `workspaces`, resolves `publishedRelPath`, checks one dev owner per published package, and
requires the conventional scripts selected by each entry's capabilities. Each check is its own `fhevm-npm check` command
and does not prove [NR-72](NR-72.md) itself: run alone, it does not discover packages the manifest omits. `make check-pre` runs
`fhevm-npm check manifest-coverage` ([NR-72](NR-72.md)) before the checks of this rule and stops at the first failure, so the gate
runs them only on a complete inventory.

> **Implemented.** `fhevm-npm check manifest-coverage` performs repository-aware discovery, excludes its own autonomous package
> tree and the paths listed by `inventory.exclude`, adds explicit standalone roots, compares the result with the
> manifest and checks realpath containment.
