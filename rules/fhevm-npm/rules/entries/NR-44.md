`forge fmt` is the sole Solidity formatter, so
`prettier:check` and `prettier:write` must exclude `.sol`. A mirror-only payload keeps its upstream Prettier setup
instead, the Solidity Prettier plugin and `.sol` in its Prettier scripts included, and does not require `forge:fmt`,
`forge:fmt:check` or `forge:lint` on its dev owner. The rendered mirror keeps Solhint on purpose: the mirror patch
does not remove it, so the published template keeps the Solhint upstream declares. The workspace form does not carry
it. In the workspace, [NR-20](NR-20.md) forbids the package unless the payload's manifest entry lists it in
`dependencyExceptions`, and no entry does; the banned-linter scan of `fhevm-npm check lint-policy` skips mirror-only
trees, so a Solhint configuration or directive there is not reported.

```jsonc
// ✅ Solidity is intentionally absent.
"prettier:check": "prettier --check \"**/*.{js,json,md,ts,yml}\""

// ❌ This gives Solidity two formatters with potentially different output.
"prettier:write": "prettier --write \"**/*.{js,json,md,sol,ts,yml}\""
```
