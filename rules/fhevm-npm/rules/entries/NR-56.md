It creates a fresh temporary directory outside the checkout and
copies or generates the consumer there. A non-member nested below the workspace root is not isolated: Node can still
walk up to the root's `node_modules` and satisfy an undeclared dependency.

```text
✅ /tmp/fhevm-consumer-abc123
❌ /repo/hardhat/v2/plugin/test/consumer
```
