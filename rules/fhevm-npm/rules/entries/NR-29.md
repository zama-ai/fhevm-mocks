The repository declares one exact
version in `npm-manifest.json#foundry.version`, compared with `forge --version` by `fhevm-npm check foundry`. Packages must not
duplicate the pin in `.foundry-version` files.

```jsonc
// ✅ One repository-wide pin, checked automatically.
"foundry": { "version": "1.2.3-v1.2.3" }

// ❌ A package-local pin can drift from the repository policy.
some-package/.foundry-version
```
