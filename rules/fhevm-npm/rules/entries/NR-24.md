The generator writes a
face into `host-contracts-cleartext/<gen>/` for every listed key, so the list must equal `<vN>` and `<vN-1>` by directory
basename. A retired key makes the generator write into a directory that no longer exists; a live generation missing
from the list receives no face, and `fhevm-npm check cleartext-config` cannot miss a face it was never told to expect.

```jsonc
// ✅ With generations.current = ./host-contracts-cleartext/<vN> and previous = ./host-contracts-cleartext/<vN-1>
"appliesTo": { "generations": ["<vN-1>", "<vN>"] }

// ❌ <vN-2> is retired, and <vN> — live — would get no face.
"appliesTo": { "generations": ["<vN-2>", "<vN-1>"] }
```
