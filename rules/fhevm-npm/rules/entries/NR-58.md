  - 'Gap, loose check: The existing Forge fixture installs only forge-fhevm-std, while the release workflow set also contains the v3 plugin and current host contracts. No consumer installation includes all three, and resolveLinkedDependencies takes no release-set input. Adding an unrelated payload to the release set cannot make a consumer check require it. Fix: issue I-109.'

One clean install names every candidate in the release
set, so a local plugin cannot silently test against an older dependency fetched from npmjs.com.

```jsonc
// ✅ Both candidates are under test in the same dependency graph.
"devDependencies": {
  "@fhevm/hardhat-plugin": "file:/repo/hardhat/v2/plugin/pkg",
  "@fhevm/host-contracts-cleartext": "file:/repo/host-contracts-cleartext/<vN>/pkg"
}

// ❌ The plugin candidate can resolve the host-contracts package from the registry.
"devDependencies": { "@fhevm/hardhat-plugin": "file:/repo/hardhat/v2/plugin/pkg" }
```
