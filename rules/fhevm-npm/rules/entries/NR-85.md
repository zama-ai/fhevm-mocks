A flat record (`<stack>/deploy.config.json`, the layout before events
had folders) may move into `<stack>/00-deploy-v<release>-<YYYY-MM-DD>/` once, as a pure move: every file renamed with
identical bytes to the same relative path under one such folder, nothing added to it; as in [NR-84](NR-84.md), an untracked new file
is judged once git tracks it. Until then it is checked as a record and reported as a note.

> **Implemented.** `fhevm-npm check deployments` checks a legacy record that has not moved, and reports it as a note. It runs in `make check-pre`. `fhevm-npm check deployments --base <ref>` checks a record that moved. It runs in the workflow `sdk-cleartext-deployments` on every pull request. Both are generation-free.
