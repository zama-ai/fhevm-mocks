`event.json`'s `defining`, `first` and `last` transactions are in the journal at the
blocks it claims, with `first.block <= defining.block <= last.block`; `defining` is `last` for a deploy event and
`first` for an attempt of any kind. The folder's date is `defining`'s block day. For now, a deploy without `event.json`
([NR-79](NR-79.md)) names no `defining` transaction, and its folder's date is compared with no block day. The journal's own
timestamps are the operator's clock and date nothing.

> **Implemented.** `fhevm-npm check deployments` checks this rule. It runs in `make check-pre`, and it is generation-free.
