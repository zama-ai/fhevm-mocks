A test that talks to a
node, listens on a port or writes a shared file can collide with another: two senders race on one nonce, one test's
transactions change what another reads, two nodes claim one port. Distinct ports do not make such tests independent
when they still reach the same node or account. Tests on an in-process chain, such as Hardhat's in-process network
or forge's per-test EVM, share nothing and need no serial mode. `test-consumer` itself runs consumer packages and
fixtures one at a time.

```text
✅ forge test                       each test runs in its own in-memory EVM
✅ node --test src/*.test.js        each file creates its own in-process Hardhat network
❌ node --test src/*.test.js        every file sends to one `hardhat node` on localhost:8545, in parallel
```
