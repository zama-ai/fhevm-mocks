`check:publint` runs `publint --strict` against `pkg/`, and `attw --pack` against it too when
the payload ships type declarations; a Solidity-only payload ships none and runs `publint` alone. Every `check:*` leaf
must be reachable from `check`, except `check:mirror` (network-bound) and generator `--check` conveniences.

`attw --pack` resolves the packed types under node10, node16-cjs, node16-esm and bundler, and by default fails on a
problem in any of them. Under `--profile esm-only`, which an ESM-only payload passes, problems specific to node10 and
node16-cjs do not fail the gate; problems in node16-esm and bundler, and problems not tied to a resolution mode, still
can. Packing stays verified with no `.tgz`. The manifest gate follows `publishedRelPath` and requires these scripts, by
name, on the owning dev package; mirror-only payloads are exempt.

```jsonc
// ✅ --strict fails on warnings, and attw packs the package to resolve its types for real.
"check:publint": "publint --strict ./pkg && attw --pack ./pkg"

// ✅ An ESM-only payload: the same gate, under the profile that matches what it ships.
"check:publint": "publint --strict ./pkg && attw --pack ./pkg --profile esm-only"

// ✅ A Solidity-only payload: no types for attw to resolve.
"check:publint": "publint --strict ./pkg"

// ❌ The required script entry is absent, so no uniform gate can discover the check.
"publint": "publint --strict ./pkg && attw --pack ./pkg"

// ❌ Warnings pass silently, and a payload that ships types never has them resolved, so a broken `exports` can ship.
"check:publint": "publint ./pkg"
```
