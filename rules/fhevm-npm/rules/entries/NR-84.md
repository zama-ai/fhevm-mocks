Against a base ref, nothing under an event or attempt folder that exists at the
merge base may be added, modified, deleted, renamed or retyped, committed or not. Locally, an untracked new file is
judged once git tracks it. New event folders, new stacks and READMEs are free.

> **Implemented.** `fhevm-npm check deployments --base <ref>` checks this rule. It runs in the workflow `sdk-cleartext-deployments` on every pull request, and it is generation-free.
