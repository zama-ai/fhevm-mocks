`hardhat` is `^2.x` for one group and
`^3.x` for the next, so it cannot be root-pinned. Each hardhat major has its own installation root.

```jsonc
// ✅ In hardhat/v2/plugin and hardhat/v2/e2e; hardhat/v3/* say ^3.x instead.
"devDependencies": { "hardhat": "^2.29.1" }

// ❌ The same line in the workspace root's package.json. One root pin cannot serve two majors, and v3 would have
//    to redeclare it — breaking 4.2.1 to work around 4.1.1.
"devDependencies": { "hardhat": "^2.29.1" }
```
