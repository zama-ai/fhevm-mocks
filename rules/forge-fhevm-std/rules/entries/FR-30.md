title: Name what a function returns
short: A function name says what it returns, not how it got the result.
old: '5.2'
check: impossible
---

For example, the function that returns the plaintext of a handle is `plaintextOf`, not `read`. `read`
says how the function gets the value, and not what the value is.

Take the words from the vocabulary already in the stack: `plaintexts`, `handle`, `cleartext`, `permit`.
