title: Never compare a function against itself
short: Build the expected value from a source that is independent of the function under test.
old: '7.2'
check: impossible
---

Build the expectation from an independent source —
`LocalHostBootstrap`, a hand-computed digest, a second code path — not from the function under test.
Otherwise the assertion holds however wrong that function is.
