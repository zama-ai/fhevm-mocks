title: '`setUp` runs once per contract'
short: Forge runs `setUp` once per test contract and restores its state before each test.
old: '7.6'
check: impossible
---

Forge snapshots the state it produced and restores that
before each test. Cheatcode state armed there (a log recorder) is restored with it; a side effect
outside the snapshot — a file write, an env write — happens once, not once per test.
